Attribution and source are embedded in the supplied GLB's asset metadata.
The uploaded GLB is redistributed byte for byte. This game hides the separate
left mesh and poses/animates the right arm using the original rig. It adds a
flashlight socket at Hand.R_027 and a camera-relative parent transform.
Original geometry, UVs, textures, skin weights, bind matrices and pose clips
are preserved. Runtime poses and the separate flashlight are game additions.

Keep this attribution with the model and in the game's credits.
